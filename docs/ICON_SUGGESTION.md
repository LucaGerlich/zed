# PgBlade Icon Suggestion

## Concept
A blade/sword combined with a database symbol, representing speed and precision in database work.

## Design Options

### Option 1: Blade + Database
A stylized katana blade cutting through stacked database cylinders.
Colors: Electric blue blade on dark background, matching Zed's aesthetic.

### Option 2: Lightning Database
A database cylinder with a lightning bolt (blade shape) through it.
Colors: Zed's blue accent color (#4fc1ff) on dark gray (#1e1e1e).

### Option 3: Minimal PG
The letters "PG" in a monospace font with a subtle blade/slash through the middle.
Style: Clean, geometric, works at small sizes (16x16 for sidebar icon).

### Option 4: Shield + Query
A shield shape (safety/production protection) with a SQL cursor (>) inside.
References the production safety features.

## Color Palette
- Primary: #4fc1ff (Zed's accent blue)
- Secondary: #1e1e1e (dark background)
- Accent: #569cd6 (SQL keyword blue)
- Warning: #f14c4c (production red)

## Technical Requirements
- macOS .icns format (multiple sizes: 16, 32, 64, 128, 256, 512, 1024)
- SVG source for scalability
- Works on both light and dark backgrounds
- Distinguishable at 16x16 (sidebar icon size)

## Recommendation
**Option 2 (Lightning Database)** best communicates what PgBlade does:
- Database cylinder = PostgreSQL
- Lightning bolt = speed (Zed's core value)
- Clean enough to work at small sizes
- Distinct from both Zed (Z) and DBeaver (beaver) icons
